## 历史：早期盘点与里程碑日志

### 兼容性探针（compat_probe）

运行在 DSH 宿主内的动态 Cordis 插件（host 半部），采集**运行时兼容面**：

- code-runtime 后端（`language` / `isolation`）— 现在是 `typescript` / worker-thread，Zig 版应为 `typescript` / quickjs-context
- sandbox 模式与 workspaceRoot
- sessions / agents / subagents providers 计数与清单
- 工具清单（toolCount + 全部工具名）、skills 数量、llm providers
- workspaces（id/path/title）、loader 插件树条目（id/name/disabled）
- probeNotes：每个采集环节的超时/错误诊断；persistError：文件落盘诊断

**用途**：Node 宿主与 Zig 宿主各跑一次，diff 两份报告 = 重写兼容性的可执行检验。插件本身是 cordis 插件（纯 JS），在同一套契约下天然可运行于两个运行时。

**沙箱事实**（源码 `cordis-host-runner/src/sandbox.ts`）：动态 host 半部在 `node:vm` 沙箱中运行，无 `process`/`require`/`fetch`/timers；仅暴露 `ctx`/`harness`/`console`/`TextEncoder`。因此探针只通过 cordis 服务（`ctx.get()`）采集，报告以**工具结果**为主通道，fs 落盘为 best-effort（动态插件在会话 fs 作用域之外，通常不可用）。
